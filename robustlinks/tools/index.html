Robust Links - Tools


For web page authors and web masters that want to combat link rot in their pages:
  • The Robust Links JavaScript and CSS code, available from the IIPC Robust Links GitHub repository, can be embedded in web pages by linking to their respective persistent URIs:
    • https://doi.org/10.25776/h1fa-7a28 for a JavaScript
    • https://doi.org/10.25776/z58z-r575 for a CSS
    The JavaScript leverages robustified link information embedded in HTML pages as a means to dynamically present various navigation options, including following links to snapshots of linked resources in web archives. This allows the user to see the linked resources as they were around the time of the creation of the page or the link.
  • The robustify.js JavaScript can be embedded in web pages. It works in combination with a server side PHP script that checks whether links still work as they are being clicked. If not, the user is being redirected to a snapshot in a web archive.
For authors of web pages, to create snapshots of pages you link to:
  • Use the "My url is alive" feature at archive.today
  • Use the "Save Page Now" feature at the Internet Archive
  • Create an account and submit a URI at perma.cc
